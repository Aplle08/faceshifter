# Бібліотека стратегій C&C Generals: Zero Hour

База знань для ШІ-агента, зібрана з 76 навчальних відео YouTube-каналу **DoMiNaToR**: туторіали «How to Play», all-in білди, гайди по матчапах, Pro Tips, хоткеї, таблиці цін, правила, механіки й трюки. Стріми й касти турнірів сюди не входять.

## Структура

| Шлях | Що там |
|---|---|
| `INDEX.md` | Таблиця всіх розборів: файл, посилання на відео, статус перевірки, суть |
| `catalog.json` | Те саме в JSON: генерали, матчапи, ключові пункти, білд-ордери, згадки про продаж CC |
| `USA/`, `China/`, `GLA/` | Розбори відео, де головна армія — ця |
| `General/` | Загальне для всіх армій: поради, правила, хоткеї, баланс, FFA і командні режими, трюки |
| `General/00_SELLING_COMMAND_CENTER.md` | Перевірка тези «про-гравці продають CC»: 71 фрагмент із 28 відео, механіка за даними гри 1.04, правила для агента |
| `China/00_PROMPT_all-in-rush-china-vs-usa.md` | Готовий самодостатній промпт: all-in раш China проти USA |

## Формат файлу розбору

Кожен файл має однакові розділи, тож модель може розбирати їх автоматично:
Коротко → Стратегії та білд-ордери → Юніти → Мікро і тактика → Економіка → Матчапи і контри → Типові помилки → **Правила для ШІ-агента (ЯКЩО → ТО)** → Ключові цитати → Невизначеності.

- `[mm:ss]` — таймкод у відео, звідки взято твердження.
- `[загальне знання, не з відео]` — доповнення укладача, яких немає у відео.

## Як дати це ChatGPT

1. Завантаж усю папку `strategy-library` (або zip) чи потрібну папку армії.
2. Порядок читання: `README.md` → `INDEX.md` → розділи «Правила для ШІ-агента» у файлах потрібної армії → `General/00_SELLING_COMMAND_CENTER.md`.
3. Приклад запиту: «На основі файлів бібліотеки склади для агента стратегію за <армія> проти <армія>: білд-ордер із кроками й хоткеями, склад армії, пріоритети цілей і правила ЯКЩО → ТО. Посилайся на файли й таймкоди і розрізняй, що сказано у відео, а що є твоїм висновком».

## Застереження

- Джерело — автосубтитри YouTube, тож назви юнітів у них бувають спотворені. Розшифровки звірено з контекстом, а сумнівні місця винесено в «Невизначеності».
- Відео охоплюють 2016–2026 роки, тому баланс міг змінитися: 1.04, GenTool, Generals Online, community-патчі. Дивись дату в шапці кожного файлу.
- Усі відео одного автора. Хоткеї в нього можуть бути власні: Sell, наприклад, він перепризначив на Z.
- **Статус перевірки** вказано в `INDEX.md`:
  - **перевірено** — другий незалежний агент звірив файл із повним транскриптом і виправив помилки;
  - **лише аналіз** — первинний розбір без другої перевірки, бо роботу зупинено через ліміт.
- Ще **не зроблено**: зведені огляди армій (`00_OVERVIEW.md`), `00_BUILD_ORDERS.json`, глосарій і аудит суперечностей між відео.
